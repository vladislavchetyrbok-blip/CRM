# TapMemory 2.3 for Android

Бесплатный автокликер со сценариями для Android, воспроизведением в Chrome, вставкой текста и сменой SOCKS5-прокси. Без подписки, рекламы, обязательных серверов и платных функций.

## Функции
- Запись доступных Android-событий нажатия и прокрутки, сохранение времени пауз.
- Несколько именованных сценариев, редактирование порядка и задержек в секундах.
- Воспроизведение с семантическим поиском UI-элементов и ожиданием их появления.
- Вставка текста, добавленного из буфера обмена пользователем.
- Плавающая кнопочная панель записи/запуска/остановки.
- Бесплатный SOCKS5 VPN для **целевого приложения** (обычно Google Chrome) через Android VpnService + open-source tun2socks. Телефон остаётся подключённым к Wi-Fi.
- Переключение между SOCKS5-адресами при каждом новом цикле. Проверка HTTPS-ответа через выбранный прокси на `api.ipify.org`; при ошибке/неизменившемся IP для списка из 2+ прокси сценарий прекращается.
- Альтернативно: пользовательский HTTPS API роутера/провайдера для динамического IP.

## Бесплатный Tor (Orbot)
1. Установите бесплатный [Orbot](https://orbot.app/) из официального источника.
2. Включите **Power User/Proxy-only mode** в Orbot, чтобы Orbot не занимал системный Android VPN. Запустите SOCKS5 на `127.0.0.1:9050` (проверьте порт в Orbot).
3. В TapMemory нажмите «Добавить бесплатный Tor», включите режим «SOCKS5», одобрите Android VPN-разрешение и запустите сценарий.
4. TapMemory отправляет на Tor SOCKS5 порт отдельные параметры изоляции для каждого повтора. Tor при соответствующей настройке SOCKSPort создаёт независимые цепочки; **новый выходной IP не гарантирован**. При неизменном адресе проверка повторяет запрос до трёх попыток и затем останавливает сценарий.

Для **автоматической ротации** добавьте минимум 2 разных надёжных SOCKS5-сервера без авторизации в формате `host:port`, каждый на новой строке. Серверы и трафик не оплачиваются в самом TapMemory; платные прокси не требуются. Бесплатные публичные прокси часто нестабильны и потенциально небезопасны — не используйте через них пароли и платёжные данные.

## Архитектура
- Java Android; AccessibilityService для записи UI-событий и жестов.
- VpnService for Android, per-app VPN, отдельный foreground service.
- [HevSocks5Tunnel](https://github.com/heiher/hev-socks5-tunnel) MIT by heiher, компилируемый из исходного кода во время GitHub Actions. The upstream repository is cloned in the build workflow.
- Android NDK + native bridge. No remote backend, no app subscription or telemetry.
- `api.ipify.org` используется только по запросу для проверки выхода выбранного SOCKS5.

## Технические ограничения и безопасность
- Доступность Chrome не равна прямому чтению DOM: нестандартные области, Canvas/игры и динамические элементы могут воспроизводиться неточно.
- Режим SOCKS5 поддерживает серверы без логина/пароля; HTTP-proxy без SOCKS5 не поддерживается.
- Одновременно может работать только один Android VPN: если уже включён другой VPN, Android попросит переключить его на TapMemory.
- При переключении SOCKS5 текущие соединения Chrome могут прерваться; приложение ждёт переподключения.
- Базовое переключение прокси не гарантирует смену внешнего IP, если несколько серверов используют общий выходной адрес.
- Прокси-трафик не обязательно зашифрован между телефоном и прокси (сам HTTPS браузера остаётся защищённым TLS). Используйте только доверенные прокси.
- Ввод паролей и текст клавиатуры автоматически не записываются; содержимое буфера сохраняется только после ручного добавления шага.
- Приложение не содержит обхода капч или специальных функций для обхода ограничений сайтов.
- Debug APK предназначен для тестирования. Компиляция не заменяет QA на реальном телефоне.

Исходная версия 2.2 была восстановлена в этой ветке из доступных артефактов и требований; исходный ZIP из Work версии 2.1 не был доступен.
